# Liu 2023 微透镜阵列增量核验

对应 EVD-003b / EVD-016b；数据基线 main ed5be7f / catalog 0.1.4。本轮新增一个独立研究团队的论文，主文与补充材料分设来源入口，不能计为两项独立研究。

## 宏观定位

[Liu等，Light: Science & Applications 12, 143 (2023)](https://doi.org/10.1038/s41377-023-01174-7)研究选择性润湿、刮涂和UV固化制作的NOA-73阵列，应用目标为集成成像。华南师范大学/南洋理工大学等作者团队与已有Zhang喷墨阵列和Richards单透镜来源独立。本次收录的是实验样本，不认证题名中的“record-high”，也没有将单元、阵列、整个显示系统的分辨率相互替代。

实际读取：本机独立Chrome无头会话读取出版社HTML；读取出版社9页PDF的Results、Optical characterization、Methods等相关正文，视觉核对p.5 Fig.3和p.7 Fig.5。补充DOCX读取XML正文/表格，提取并视觉核对Fig.S8原图；未渲染整份DOCX版面、未观看视频，其余补充图未视觉核验。原始文件只在临时目录，不入库。

## 方法拆解

- 主文p.5：100 μm口径阵列在532 nm连续波、线偏振照明下，以CCD记录焦点阵列；作者对10×10个单元报告quadratic variance约0.09。正文和所读SI未提供完整公式、归一化、强度取峰值或积分、背景校正及重复测量信息。因此保留作者数值，但不赋予百分比单位、不转为“91%均匀性”，也不新增一个定义不完整的通用均匀性指标。
- 主文p.7 Fig.5a–c：405、532、633 nm对应焦距350、366、357 μm及FWHM 1.36、1.8、2.12 μm。数据来自正文，非图像估读。三个采样点焦距最大差为16 μm，明确标为本库算术派生；非连续光谱范围，也非焦距标准差。
- SI §7/Fig.S8：三个制备阶段的图像经MATLAB二值化，利用标尺估计半径；图示模板、改性区域与固化透镜半径分别约50.25、50.13、51.33 μm。最后两者之差约+1.2 μm是半径变化，不是标准差、容差规格或良率；抽样数和阈值/标定不确定性未完整交代。

## 图表核验与不合并的数值

1. Fig.3同页同时包含100 μm阵列与1 mm口径的液滴剂量系列。最大NA≈0.26属于后者，不能并入100 μm样本。正文p.4对Fig.3a/b报周期200 μm；Fig.3f峰间隔视觉上不同，样品对应未解决。未据图反算周期/填充率或擅自纠正文中的数值。
2. Fig.3f图例x/y配色与正文描述有出入；不据颜色拆出方向性能，也未做图像数字化。粗糙度0.34 nm是选中单元的局部结果，未将其扩写为全阵列质量保证。
3. Fig.5三波长焦点不是单调随波长移动。只减405与633 nm的端点得到7 μm，会漏掉532 nm的366 μm焦点，故本条展示全部三点和16 μm采样范围；未另算有效阿贝数。
4. 分辨率主文指向group 7 element 5（2.46 μm / 203 lp/mm），SI §5文字却说fifth group fourth element；SI Table S1的203位于group 7 element 5。还需核查图像处理、对比度判据和作者MTF定义，不把所有相关数字打包成一个可比较的分辨率或MTF纪录。本批不新增其分辨率最佳声明。
5. 主文p.8聚焦效率引用另一论文的定义（ref.37）。本批未读取该参考文献和完整功率链，故不将效率数字作为已统一分母的对照数据。公开原文并不等于所有口径已经可复现。
6. Fig.S8原图三个半径标签与正文一致。SI正文的system error ±0.5未注明清晰单位/统计意义，不能自动补成±0.5 μm制造容差。三个阶段图像也不是100个单元的尺寸统计。

## 批判与迁移

这项工作补足独立阵列实验和实际尺寸传递的证据，但尚未建立跨论文同条件比较。已有Zhang的88%为几何面积比，Liu的0.09为未完整定义的强度统计，两者不能排序；Liu两个数据记录及两个来源入口仍只算一项独立研究。EVD-003父任务的完整一致性方法、串扰和任务级指标定义仍未完成，EVD-016的统计容差与批次良率也未完成。

对945 μm方形超透镜，仅可借鉴“分别报告尺寸变化、光学一致性、跨波长共同面像质”的测量组织方式，不迁移聚合物尺寸偏差或NA作为其制造要求。
