# DEVICE-005: VITURE Luma Pro

Source: https://www.viture.com/en-MY/academy/xr-glasses/luma-series
Read 2026-11-13; manufacturer text, not independent measurement.

Tech Specs Comparison, Luma Pro column: explicit 1920 × 1200 per eye; maximum 120 Hz; FOV 52° with direction unspecified. Introduction identifies Sony MicroOLED. Refresh-rate section also lists 90/60 Hz, and limits One Neckband, Pro Mobile Dock and One Mobile Dock to 60 Hz.

Do not infer horizontal/vertical FOV, PPD, eyebox or eye relief. Perceived brightness lacks a measurement protocol; 4K-like/50% sharper is not native resolution or measured MTF. IPD sizes are not eyebox dimensions. Full-SBS video formats and console output recommendations do not replace panel specifications.

Supplement read 2026-11-13: https://www.viture.com/academy/spacewalker/desktop , Select a Refresh Rate: Luma Pro supports 120/90/60 Hz selection in SpaceWalker. On Windows the app overrides system refresh while active and reverts when closed. This is not proof of all-mode 120 Hz support.
