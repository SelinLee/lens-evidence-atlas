# 计算微透镜阵列：分辨率、轴向范围与处理时间核验

任务 EVD-003e。Yang等的系统为无隔板3×3塑料MLA加SV-FourierNet重建；本批可支持一个独立团队的条件化实验样本，不能替代光学串扰测量或同条件最优比较。

## 材料与宏观定位

Qianwan Yang, Ruipeng Guo, Guorong Hu, Yujia Xue, Yunzhe Li, Lei Tian，*Wide-field, high-resolution reconstruction in computational multi-aperture miniscope using a Fourier neural network*，Optica 11(6):860–871 (2024)，DOI [10.1364/OPTICA.523636](https://doi.org/10.1364/OPTICA.523636)。发表元数据已核；实际科学依据为[作者arXiv v2（2024-05-30）](https://arxiv.org/abs/2403.06439v2)，主文17页与SI34页合订，共51页。没有逐字核对最终出版版和其独立SI，也不声称全文所有公式或代码已审核。

问题是如何处理阵列中重叠的多视角观测、空间变化像差及边缘截断。方法将实验标定的PSF用于模拟训练，再对真实观测重建。作者的优越性声明限于文内比较；本库没有复现原始数据、代码、权重或独立验证“state of the art”。

## 图表核验

实际查看合订PDF pp.11、12、28、46、47、48、49（主文Figs.5–6、SI Tables S2/S3及Figs.S24–S28）；对应文字读取主文§2、§3.2–3.5、结论与SI§4/8/9相关部分。非仅根据图注推断。

- **Fig.5 / SI S24–S26**：作者主文报告7.8 μm，SI为7.81 μm。Fig.5明确中心及径向2 mm位置，SI另给五方位；没有据6.5 mm线性FOV推导全场分辨面积，也未独立标定图中USAF线宽/周期。图中曲线和标靶重建不能直接改称PSF FWHM或MTF门槛。
- **Fig.5(b) / S25**：轴向步进10 μm，报告−50至+50 μm范围内保持标靶表现；总宽为50−(−50)=100 μm。±70 μm示出退化/伪影。离散采样不能证明区间每个位置，且未取得统一数值对比度合格门槛。EDOF不是轴向分辨率、切片厚度或高斯共焦参数。
- **SI§8.C / S26**：作者明确承认边缘轻微对比度下降，9个网络通道不能完全消除截断与空间变化像差。不把摘要“uniform”写成全场逐像素验收。
- **Fig.6(b)**：特定实验靶示例显示CM²Net 1.35 s、MultiWienerNet 0.12 s、SV-FourierNet 0.06 s、LSV ADMM 54 min。Fig.6(a)的模拟PSNR/SSIM不移作实验图的量化质量。S24边缘ADMM另为57 min，本记录没有混成统一时间。
- **Table S3（SI p.11 / PDF p.28）**：1/5/9/15/30网络通道分别0.0499/0.0578/0.0668/0.0813/0.1162 s。9通道为作者质量、时间、内存的折中，既非最快也非最高PSNR；网络通道不同于物理透镜个数。0.0668 s与主文0.06 s保留各自入口，不平均、不独立计为两团队。
- **S27 / SI§8.D**：按径向分箱的PSD来自模拟测试重建；另有实验样本能量归一化后的PSD。约0.14 μm⁻¹换算约7.14 μm周期，量纲正确，但PSD受样本频谱影响，不能充当MTF或并入靶标7.8 μm排名。

## 局限与下一步迁移

本批增加“图像重建处理时间”和“可用轴向范围”定义及一个15参数样本，阵列应用增加有出处的任务权衡，不增加重要性名次或最佳声明。0.06 s的倒数只可能是在单帧串行、无其他开销假设下的理想处理率，原文不足以证明采集到显示的实测实时帧率。A40实现说明不单独证明所有比较的硬件、GPU同步、预热、batch与前后处理边界一致。

下一步需取得同协议独立样本、端到端计时与质量验收条件；若用于具体阵列设计，应分别测裸光学PSF/串扰、重建误差与场点/深度性能。还需父任务中的逐单元焦距/波前和跨批次公差。没有将本研究归为与Katopodis针孔ROI相同协议的串扰对照，也没有用本批关闭这些缺口。
