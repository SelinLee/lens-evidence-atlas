## 1. 问题与来源

前批已处理LBT单误差模型和He组合失配，本批补充独立团队的多件单接口实验，保留实际测量的不足。原始论文：Arkadiusz Woźniak、Mateusz Łakomski、Przemysław Niedzielski，2026，Materials 19(5),1013，[DOI 10.3390/ma19051013](https://doi.org/10.3390/ma19051013)。出版社HTML与下载的19页PDF均直接核读相关位置，PDF仅临时用于研究，不入库。

## 2. 逐项核验

- p.6 §3.2 Eq.(3–4)视觉核验：η为归一化重叠乘Fresnel透射因子，IL=−10 log10η。该公式不会补足实验参考面。dB均值反变换不是线性效率算术平均。
- p.9 §4.1 / Fig.6：LEOF与SMF-28e+单接口，短间距干涉以每点100次测量平均处理；这不是100个器件或独立团队。
- pp.10–11 §4.2 / Figs.8–9：五个同程序随机样品，直径40 μm、曲率半径32.5 μm。正文给TX接触/优化均值0.76/0.39 dB，RX为约0.67/0.40 dB，只保留作者报告。
- Fig.8b内嵌表按样品1–5列TX间距19/22/23/22/22 μm；Fig.9b列RX间距28/23/26/26/30 μm。已核原图及PDF，不从曲线估数。
- pp.11–12 §4.3 / Fig.10明确该系列1550 nm及0–100 μm纵向扫描。间距是各样品工作点，不是1 dB允许公差，五件来自同一研究。

## 3. 保留的争议和排除

Fig.8b/9b均值方块的视觉位置与正文0.39/0.40 dB均存在一致性疑问；没有原始数据和聚合权重，不能确定原因或替换作者值。两个方向聚合均未复现。正文损耗范围的统计对象不够清楚，不把极值范围当置信区间或样品均值范围。实验功率校准面、损耗扣除和偏振仍缺。

§3的数值容差仅仿真，其直径–曲率映射与制造段/§4.2有不一致；本条只采用§4.2实验几何。§4.3 Table 1邻近37 μm讨论，样品归属未核实，不并入本40 μm五件系列；§4.4七芯FIFO亦不拼接。未新增coupling百分数，以免将dB平均反变换冒充平均效率。
