# 微透镜面形与低光通量质心检测

任务EVD-003h；核验2026-11-07。[Rouquette等作者v1](https://arxiv.org/pdf/2607.26543v1)，2026-07-29，存档DOI10.48550/arXiv.2607.26543。已读14页全文、视觉检查全部图页；未核同行评议出版版、原始测量数据或其引用文献。PDF元数据题名是模板残留，首页题名与arXiv一致。以下页码均PDF页序。

## 宏观定位

研究的是MORFEO/HARMONI的LGS Shack–Hartmann波前传感：微透镜面形误差怎样影响低光通量下的光斑定位，再怎样影响多导星AO性能。§2 p.2明确以质心方差为这一检测任务的主要评价量，能补任务依据，但没有给所有微透镜阵列用途的指标排序。

贡献链为“面形测量 → 单元PSF/噪声模拟 → AO等效噪声模拟 → 台架测量与模型比较”。各环节证据性质不同。两个库内记录来自同一团队，不是两个独立实验来源。

## 方法拆解

- §2.1 p.2：Wyko NT9100测真实面形，以拟合球面为参考。Eq.1的Δ=(n−1)(z_real−z_ideal)是该表面模型的光程差，长度单位；转为相位后FFT得到PSF。不能把表面高度直接当波前RMS，也不把计算PSF说成实测。
- §2.2 p.3：模型光斑与LGS源分布卷积，再采样到14×14像素、1.2 arcsec/pixel。§2.3的解析高斯源和物理钠层模型分开。
- Eqs.2–8 pp.5–6：WCoG有高斯权重及乘性响应校正b，方差含光子噪声与读出噪声。权重宽度比β典型取2；有限窗口修正含erf。p.6非拉长例子Lx=Ly=1.5 arcsec，10,000次Monte Carlo。未独立重建整套解析或数值模型。
- §3/Table1 pp.9–10：39 m、6个589 nm导星、68×68子孔径；此处像素尺度1.15 arcsec，与单元模型1.2分开保留。用高通量方差比倒数表示等效throughput，并非全阵列相位逐单元传播或真实透过率测量。MMSE和多导星冗余参与系统结果。
- §4 pp.11–13：台架用400 μm芯径LED多模光纤、平镜模式SLM、C-BLUE相机。Fig.12滤光片标589±4 nm；其带宽定义和实测谱未给，不能改称FWHM。45 mm焦距、24 mm直径是准直元件，不能抄成微透镜参数。500 Hz、每子孔径1000帧；光子标定G=0.24 e⁻/ADU、QE=0.7 e⁻/ph。比较基准为同实测通量/FWHM的高斯理论方差。

## 批判与迁移

保留而不默默修正的缺口：

1. Fig.1相位轴写φ(°)，图注写radians。未据此提取相位RMS。
2. p.6写σ²_RON=2.5 e⁻/pixel，方差符号和单位不一致；未代作者决定它是方差或标准差。
3. 单元与系统像素尺度不同，Fig.8横纵方向不同；两者可能是条件差异，不能统一抹平。
4. Fig.9模拟#3最好，§4/Fig.16台架#2中位数最低。不同抽测单元与整阵列分布可能解释差别，但样本对应、条件和不确定度不足，不能据此合并出一个sag排序。
5. 台架超额方差被作者归于面形；漂移、响应和标定误差未在可读材料中逐项独立分离。统计精确通量、有效子孔径掩模、原始帧、制造工艺/尺寸及误差预算仍缺。
6. 本稿支持任务级“面形影响检测”的证据，不提供微成像透镜普适合格线，也没有建立阵列制造误差到系统指标的独立可复现公差预算。

本库补充的量纲/极限核对：Var(C)是位置平方单位；R同单位相除无量纲；标准差比√R。理想基准完全重合时R=1。若方差模型为a/N，则把方差系数乘R后需要R倍光子恢复基准；若为b/N²，则对应√R倍光子；混合项一般没有固定倍率。这是代数解释，不是新的实验数据。台架Nph的单位为(e⁻/ADU)×ADU/(e⁻/ph)=ph。

后续优先核独立质心算法原始论文及读出噪声校准源，明确低通量噪声区间；取得原型单元与阵列映射后才能讨论sag/制造关系。若用于主线透镜设计，应先确定实际成像或波前传感任务，不能直接把这组阵列的1.81或1.25×当我们的验收标准。
