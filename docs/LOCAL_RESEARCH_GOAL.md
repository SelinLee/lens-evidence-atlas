## 持续提取与证据要求

优先补口径、NA、设计焦距、材料/基底、结构高度/周期、工作波段与实际谱点，逐步取得逐波长实测焦距、轴向焦移、横向色差、PSF/FWHM、MTF、Strehl和聚焦效率。

每个数值按现有格式保留`source`、`location`、`note`、`basis`，并记录单位、约值、误差、所读版本/范围和真实核验日期。定位到原文图表/子图、公式或数据文件的具体行列/工作表/单元格。主文、SI、数据文件与勘误相互核对；关键图、表和公式按需视觉复核，不能只靠可能错序的文本提取。

| 证据 | 必须保留的条件 |
| --- | --- |
| 逐波长焦距与轴向焦移 | 同一器件、实际谱点、参考焦面或参考波长、符号/单位、轴向采样与误差；设计焦距不代替实测，作者带内变化幅度不分派成单谱点有符号焦移。百分数说明分母，未知定义保留原述及缺口。 |
| 横向色差 | 场角/像高、比较通道、评价面、单位和光学/系统/处理归属；轴向稳定不推成全场无横向色差。 |
| PSF/FWHM与Strehl | 波长、偏振、方向、场点、固定或逐波长最佳焦面、采样尺度、归一化及参考模型；方向不明不平均，曲线界限不填常数。 |
| MTF | 空间频率及单位、方向、场点、颜色/波长、评价面、归一化和获取方法。PSF复算须有原始数组、物方采样尺度及处理条件；本库复算单独标记输入文件、算法与结果。 |
| 聚焦效率 | 积分焦面、焦圈半径或直径、功率分母、偏振/检出通道、测量波长及聚合方式；指定波长值与带内均值分列，不混入单元转换或偏折器效率。 |

仅核到曲线、上下界、冲突或数据获取声明时，记录图号、坐标轴、方法、查过的入口和仍缺材料，未核数值留空。读图估值不能冒充作者原始数表。查无匹配与入口无法访问分开记录，不能由有范围的检索断言全网不存在数据。量纲、单位换算与适用极限按实际完成情况记录，不以理想模型反填作者未报告的实测值。

## 统一展示与可见光筛选

继续使用现有统一散点图、侧边筛选、按论文归组的表格和编号来源，不为新论文另建展示体系。全部应用共用模板；其他历史应用的数据保留，不因此恢复其主动调研队列。

- 两轴指标可选，样本之间不连线；重合点可辨认，未知值不补零。区间、复合值、误差和不同单位不暗取单值或静默合并；无值指标标注缺口，旧分享链接可恢复已有数据视图。
- 悬停或选中点显示两轴投影与读数；图点可进对应样本，数据格跳到原始材料，来源可返回对应行/单元格。分享与CSV/SVG导出保留筛选、数值性质和出处。
- 「仅可见光」采用380–780nm（含端点），优先判断本条实际测量波长，其次判断已知工作波段是否交叠；明确可见光用途的汇总配置也可纳入，波段与用途均未知时隐藏，不捏造连续带宽。
- 桌面常用尺寸下图表与常用设置同屏，窄屏保留主轴设置/图表与可关闭筛选层。保留旧入口和参数；资源按内容版本加载，加载失败给出恢复操作，不能留下空白图。

## 手机与VR/AR的保留维护范围

手机按型号、地区/代际、镜头模组、拍摄模式、焦段和处理链维护；VR/AR区分光学透视、视频透视、沉浸式与科研原型，保留颜色、场点、眼位和显示模式。跨品牌先进型号覆盖需有检索截止日期与纳排依据，历史设备或同厂变体不代表已完成先进设备覆盖。

继续维护指标定义、任务级评价依据、逐型号参数矩阵及可选轴图表，优先有协议的SNR、MTF和成像色差。裸镜片、传感器与计算摄影整机输出分开；PSNR不替代SNR，面板像素/亮度不替代入眼或系统分辨率，作者标称不改作独立实测。未知定义、统计、标尺或协议在数据格及来源中可查，不强行建立统一重要性或最佳排名。
