# EVD-003c · 阵列质心间距的一致性与统计差异

## 研究问题与来源

微透镜阵列缺少可定位的均匀性定义和独立实验。此次只补**空间焦斑间距**统计，不以这一量替代强度、焦距、制造容差或串扰。

- Zhao, Fangyuan; Feng, Zhigang; Shan, Shuonan，清华大学深圳国际研究生院，2025。
- *High-Density Arrayed Spectrometer with Microlens Array Grating for Multi-Channel Parallel Spectral Analysis*，Sensors 25(15), 4833，[DOI](https://doi.org/10.3390/s25154833)。
- [原文PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC12349526/)；§3.2锚点 `sec3dot2-sensors-25-04833`、[Table 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC12349526/#sensors-25-04833-t001)、[Fig.4](https://pmc.ncbi.nlm.nih.gov/articles/PMC12349526/#sensors-25-04833-f004)。
- 来源 `zhao_mlag_2025`，实验记录 `zhao_mlag_spacing`，定义 `array_spacing_cv`；沿用app_14，不增加应用或排名。

## 四步核验

1. **读取范围**：2026-11-06直接通过普通云浏览器读取§3.2全文、Table 1完整六行及CV行、Fig.4图注与实际渲染图像。另查摘要、邻近§3.3.1–3.3.3及结论辨别条件归属。不是全文精读或PDF视觉核验。
2. **测量对象**：作者计算焦斑质心，从零级焦点测向右与向下相邻焦斑的像素间距；移动MLAG在不同位置取样。Table 1公开六组配对间距，只计同一团队的一项实验，不按六行增加独立来源数。
3. **计算与量纲**：CV=SD/mean，百分数再乘100。长度单位相除后无量纲；均值为零时不定义。作者未指定样本或总体SD。本库分别检查两种口径，明确属于算术派生，不冒充新测量。
4. **图文核对与冲突**：Fig.4实际图像包含复合光、MLAG、CMOS和−1/0/+1衍射区域。§3.2写蓝绿复合光，未给数值波长；摘要把1.11%关联638 nm，两处对应关系未知。§3.3.1另一个实验的660/520/450 nm不填进Table 1条件。
