# 全应用统一展示模板 — 2026-11-14

用户要求手机镜头与AR/VR沿用全项目同一个展示模板：折线图为主、侧边设置、下方表格及类似文章引用的来源，并能在单元格与来源之间往返。用户随后询问连线含义，界面已明确长折线是按横轴排序连接样本，短细线连接标签与圆点；两者不表示时间趋势或性能排名。

## 本批范围

基于`main`的`6d747f94469cfd6399931ec0aeb96d1acdac3737`。当前33类应用及手机/XR两类型号域共35个选项使用统一入口；没有合入开放PR #69的数据，不修改其他工作分支，不重新核验论文/产品或刷新数据核验日期。

- `index.html`首屏为可切换折线/散点的双轴图表，旁边集中设置应用、模组、证据类型、轴、样本、表格列及导出；长名单局部滚动，整个页面无需下滚才能改轴。
- 1440×900、1366×768、1280×720及768×1024保持设置与图表同屏；390×844、320×844以紧凑主设置和图表同屏，样本/列设置在原生可关闭对话框中操作。窄屏图可局部横向滚动，图例保留所有型号与坐标。
- 图表下方是保留原始参数、缺失、证据性质、核验日期、原文位置的表格；底部连续编号参考文献保留标题、URL/DOI及读取范围。表格单元格到来源、来源到行/单元格双向跳转；图点与图例也能进入同一份数据。
- 保留全部原指标词典、任务权衡、限定范围参考、低NA条件对照及完整参数弹窗。`devices.html`转入统一入口并保留选择参数，兼容旧型号名称筛选、旧设备来源/定义锚点和`#app_04/compare/...`入口。
- 表格和图从相同的数据适配结果生成，未复制科学数据。旧数据按原始参数名与单位分列；只接受明确标量，不猜测语义映射、不隐式换算单位，不把复合值、区间、误差或近似描述压成数值。旧记录仅有记录级来源时明确写出定位尚缺。
- 设备适配保留研究行、逐格basis、测量范围及任务依据，避免后续PR #69合入后误标为厂商规格。本批的来源未重新阅读，兼容性不等于认可尚未合并的数据。
