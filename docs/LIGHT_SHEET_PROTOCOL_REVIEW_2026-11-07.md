## 方法拆解：实际可确认的协议

| 环节 | 固定版位置 | 读到的行为与解释 |
| --- | --- | --- |
| 生成三维强度 | `simulatebeam_gui.m`末段、`GeneralFunctions/propVolInt.m` | 场传播后得到I=abs(E)²；数组第三维是传播步 |
| 生成扫描光片剖面 | `GeneralFunctions/integrate_and_slice_gui.m`，`PSFSumY`赋值及其绘图 | 对第二数组维求和；输出图横轴是物理传播y，纵轴是检测z。内部变量x/y命名不能直接当论文物理轴；此求和不是只截取静态束中心线 |
| 含能量宽度 | `GeneralFunctions/osWidth_gui.m` | 阈值1−1/e≈0.63212056；分母为整个输入有限剖面之和，分子为一个连续窗口内和。窗口在峰值附近移动，不固定中心对称；实现限制搜索起止，不能泛化为任意剖面的全局最短区间 |
| 离散宽度 | 同上循环与返回值 | 从g=4步开始，分子含i…i+g共g+1个点，输出g×dy；这是端点距离约定，应报告步长/积分规则，不在未分析采样模型前直接称为差一像素错误 |
| 主峰宽度 | `GeneralFunctions/pWidth_gui.m` | 每个输入剖面按自身最大值归一化，阈值1/e；两侧最近阈值外采样点距离减一个步长，无插值。不是FWHM或高斯1/e²半径 |
| 报告宽度的位置 | `GeneralFunctions/analysisbeam_gui.m` | 先找中心传播线最大强度的位置，在该列求主峰和含能量宽度；长度则用所有传播列的含能量宽度。最大强度位置不必等于最小宽度位置 |
| 长度 | `GeneralFunctions/doubleOS.m` | 以最小含能量宽度为基准，找两侧达到两倍阈值的最近离散点，返回两端间全距；任一交点缺失返回NaN，不是无限长。未调用的`z2OS.m`有不同签名/分支，不能混作该GUI实际路径 |
| 物理尺度 | `prepare_data_gui.m`、`derivePhysicalAndNumericalParameters.m` | 输入nm先转μm，介质波长为λ0/n；横向步长是介质波长除以l_pixel，传播步长为其16倍。默认数组和采样设置不是所有论文图的已核配置 |

`osWidth_gui`虽计算了累计和归一化变量，但后续判断实际使用逐窗口求和，不能只凭变量名推断分位数算法。峰值在首样本时搜索窗口为空直到返回NaN；窄于网格的中心尖峰仍受4步搜索起点限制。这是静态分支分析，未声称已在MATLAB执行。`pWidth_gui`首样本峰值分支引用未作为参数或局部定义的`sym`，也需在运行验证时处理；本次不修改上游代码。

两光子边界：`LightSheet_Simulator.mlapp`的`SimulateButtonPushed`调用模拟器后直接调用积分函数，`AnalyzeButtonPushed`再调用宽度分析；`ExcitationDropDownValueChanged`只设置选项。所读`prepare_data_gui`的Two photon分支改变采样数，传播输出仍为I=|E|²，未见在扫描积分前将其转成I²的步骤。因此不能据下拉框确认双光子响应已实现或论文Fig.4已复现；也不能据此断言论文采用的全部脚本都缺该操作。尚未找到论文计算脚本与此GUI版本逐一对应的证据。

## 图表核验与未解决差异

- Fig.2 a/b为y-z剖面；c–f以37%线示主峰宽度，g–j以63%阴影示含能量范围。多峰示意中阴影可涵盖旁瓣，不能从主峰阈值宽度推导整体激发范围。没有从示意图读取实验μm数值。
- Fig.2上方标y=0、y=L，图注也写y=L；d/f/h/j的纵轴却写I(y=L/2)。这与代码明确的双侧全距有关，但不擅自裁定出版物哪一处应更正。
- Fig.3显示单峰与多峰情况下照明PSF、检测PSF及两者乘积的关系。多峰有更远的激发区域；红色系统PSF范围不是整片照明宽度，也不能从示意图算真实图像对比度。
- §3.1.1/Fig.2为63%，§3.1.2为67%；固定版代码只证实该实现用1−1/e。保留双方，不把代码当正式勘误。Fig.4/5原图本轮未视觉复核，不增加图中性能数字。

## 量纲、极限与迁移

下列是本库补充的代数检查，不是作者实测或MATLAB输出：

1. 均匀采样下分子/分母共同的步长消去，比例无量纲，最终宽度乘步长后为长度；改变截断窗口会改变分母，故需做窗口和步长收敛检验。
2. 理想自相似高斯w(y)=w0√[1+(y/zR)²]。宽度倍增发生在y=±√3 zR，因此双侧全长2√3 zR；√2倍时才是2zR。例如zR=10 μm分别为34.6410 μm和20 μm，二者不相等。
3. 扫描积分与平方不可交换：离散强度[1,2]的平方和为5，先求和再平方为9。两光子响应链需给操作顺序、脉冲和采样条件；该算例仅说明运算差异，不是光片实验。
4. 全宽=2h只对同一积分区间成立。作者峰值附近滑动区间不能无条件换成Shi固定对称半宽h63；0.63、1−1/e、0.67也不能静默合并。
