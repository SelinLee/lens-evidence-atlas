## 每批日志模板

复制到本文件，日期和结果据实填写；较长检索表可放在同目录的独立批次文档并链接。

```text
## YYYY-MM-DD-NN · 本批问题

- 执行者 / 对应任务 ID：
- 起始数据版本 / 提交：
- 分支 / Issue / PR / 合并提交：
- 研究问题与本轮读取范围：
- 新增或纠正的结论（来源 ID、原文位置、数据文件）：
- 证据性质（实验 / 模拟 / 商业标称 / 规范 / 理论）：
- 实际检索路径（平台、检索词、日期、纳排理由、无结果路径）：
- 来源独立性与可比较条件：
- 冲突、不确定性、未读到或未报告项目：
- 验证（实际执行的测试/构建/页面检查及结果）：
- 发布（未发布 / 私有发布成功；实际部署版本及核验）：
- 已满足的验收项与仍未完成项：
- 受阻事项、解除条件及可继续的工作：
- 下一步（具体问题、待读来源/原文位置、预期数据落点）：
```

停止或遇到运行限制前，保存已核验的增量数据、真实检索记录和检查点；未验证内容保持候选/待补状态。没有合并或发布就明确说明，不能把任务结束等同于证据补齐。
