一、目标

让研究者选择具体应用后，可以查到：
1. 应评价哪些指标，以及各指标的定义、单位和计算/测量方法。
2. 哪些指标更重要、为什么重要、适用什么任务。
3. 正式要求、典型商业水平、科研实测结果，以及限定条件下的最佳水平。
4. 每项结论的明确出处、原文位置、核验日期和证据边界。

不要只交付检索列表或工作计划。取得的证据必须落实为数据文件、文档、测试通过的网页更新和 Git 提交。

二、先检查项目，再开始补齐

读取 AGENTS.md、README.md、CONTRIBUTING.md、
docs/EVIDENCE_POLICY.md、docs/ROADMAP.md，以及数据结构和校验脚本。

审计当前资料，建立持久化任务清单：
- 哪些应用缺指标定义；
- 哪些重要性判断缺直接依据；
- 哪些样本缺测量条件；
- 哪些来源只是摘要、索引或厂商声明；
- 哪些最佳声明缺比较集合；
- 哪些资料需要更新版本或复核。

优先深化现有应用，不以不断增加应用类别代替补齐证据。

三、当前研究范围与交付

仅主动推进手机镜头/摄像头成像与AR/VR显示两类。对两类分别完善有出处的指标词典、先进型号覆盖清单、纵轴型号/横轴指标的参数表，以及可选横纵轴指标、按型号打点的交互图。散点和按横轴排序的折线均须支持，连线含义须标注。手机模组/地区/拍摄模式、XR类别/每眼口径/测量模式分别保留。

当前范围、候选指标、表格/图表行为及逐项验收见[本机研究目标](LOCAL_RESEARCH_GOAL.md)。优先核对已有PR #59及依赖增量，复用已验证成果；不把尚未合并的候选写成线上版本。其他旧任务保留记录，未经用户重新指定不继续推进。

四、来源与核验要求

- 优先原始研究论文、学术书籍、同行评议综述。
- 综述用于发现和比较文献；关键数字和纪录尽量回到原始研究。
- 规范性要求以适用的正式标准为准。
- 商业参数采用原厂数据表，明确它是厂商声明还是独立实测。
- 维基百科可作为线索，不作为关键定义、重要性排序或最佳纪录的唯一依据。
- 搜索摘要、模型记忆和其他 AI 的回答不能充当已核验的原文。

每条关键结论记录：
标题、作者或机构、年份、DOI/原始链接、版本、
章节/公式/图表/页码、实际读取范围、核验日期。

只拿到摘要或节选就明确标注；未读到的内容不能声称已验证。PDF 中关键公式、表格和图注应检查页面，防止文本提取错序。

五、重要性排序必须诚实

严格区分：
A. 原文明示的排序或定量权重；
B. 根据明确文献依据整理的编辑性优先级；
C. 尚无足够依据，保持未建立排序。

A 必须能定位到原文的顺序或权重。
B 必须逐项说明任务、理由、出处及推理边界，不能伪装成作者排名。
C 不得根据规格表排列顺序或个人直觉补齐。

不存在统一排序时，可以按子任务分别讨论，或给出并列的重要指标及权衡关系。不要强行产生 P1/P2 或百分比权重。

六、“最佳水平”必须限定范围

分别维护：
- 正式标准的门槛；
- 商业产品的标称规格；
- 科研实测结果；
- 数值模拟结果；
- 论文内部最佳；
- 本库同条件候选中的最优；
- 理论界限。

不得混为一张无条件排行榜。

比较前核对：
波长与带宽、孔径、NA、介质、瞳形、共轭、
偏振、视场、焦面、空间频率、
效率分母和积分范围、处理算法、实验或模拟性质。

条件不一致或缺失时，说明为何暂不能排名。缺失值不能按零或通配符处理。

本库最优必须记录候选集合、检索截止日期、纳入排除规则和比较协议。不要把单个样本或综述中的最大数字标成全球最佳。只有完成足够明确的系统检索后，才讨论是否具备建立纪录声明的条件。

七、补齐样本时关注研究价值

对重点应用尽量取得多个独立厂商或研究团队的样本；同一论文的不同型号和变体不能冒充多个独立来源。

同时记录限制、负面结果、制造容差和测量不确定性，避免只收集最高数值。

发现来源冲突时保留双方、定位差异，判断是否源于版本、定义或测试条件不同；无法解决就标记争议，不擅自选取更好看的数字。
