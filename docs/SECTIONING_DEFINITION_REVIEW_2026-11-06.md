# 光片主峰与含能量宽度：限定方法核验

## 范围与证据

EVD-002c，2026-11-06。Remacha、Friedrich、Vermot、Fahrbach，Biomedical Optics Express 11(1), 8–26 (2020)，[DOI](https://doi.org/10.1364/BOE.11.000008)。在线日期为2019-12-02，年份按卷期记录。

## 定义位置与处理

| 问题 | 原文位置 | 本库处理 |
| --- | --- | --- |
| 主峰宽度 | §3.1.1、Fig.2c–f图注 | 原文1/e≈37%峰值口径；与已有FWHM分列，不能对多峰光片直接换算。 |
| 含能量切片宽度 | §3.1.1、Fig.2g–j图注 | 包含1−1/e≈63%能量的范围；必须保留积分协议、全宽/半宽、位置及响应条件。 |
| 同文比例冲突 | §3.1.2中段 | 原文另写67%；不擅自修成63%，也不据此计算新性能数值。 |
| 传播距离 | §3.1.2 | 厚度加倍的定义不同于通常瑞利范围的√2倍判据；先统一单侧/双侧和阈值。 |
| 模型与成像边界 | §3.2、§4、Appendix B | 文中线性/双光子仿真不能冒充实验；照明切片量不单独决定实际系统对比度。 |

新指标 optical_sectioning_width 的“较低通常有利”仅指固定能量/积分协议下更薄的激发范围；不是通用光束优劣顺序。没有把63%或37%写成测得的效率。
