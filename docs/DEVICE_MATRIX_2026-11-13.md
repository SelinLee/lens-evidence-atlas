# 手机及 AR/VR 指标矩阵 · DEVICE-001

## 范围与证据
手机成像与 AR/VR 显示分别建模。首批包括3款手机的9个相机模组配置、3款XR设备和25个字段，提供型号表格与可选择双轴的散点图。

2026-11-13读取六个厂商官网规格页面的相关文字。逐项URL、读取范围和段落定位见 data/devices.json。数值均为厂商公开规格，不是独立实测，也不是完整市场清单。

## 定义与比较边界
字段词典是首批数据契约，不是标准定义全集。像素数、F数、厂商焦段和FOV不替代SFR、动态范围、SNR等质量测量。可变光圈保留完整档位。Samsung长焦行目前选择5x模组，3x仅在备注保留，不表示完整多长焦覆盖。Apple焦段未核等效口径，不反推入瞳。

XR水平、垂直和方向未说明的FOV分别列示。每眼面板像素与系统总像素区分，不将Vision Pro总像素除二；12 ms photon-to-photon不当作motion-to-photon。未验证数值不入坐标，缺失值不补零。不同型号绘制散点，不连成时间趋势，也不生成性能排名。

## 保留的缺口
- 手机：同条件RAW/JPEG SFR、畸变、色差、SNR/动态范围和眩光；真实焦距、传感器物理尺寸及第二长焦模组选择。
- XR：光学透视AR样本、入眼亮度、眼盒、眼距、显示MTF和同条件实测；PPD的场点与定义。

## 验证记录
独立功能分支基于主线94d1ad4，仅包含手机/XR矩阵功能；现有科研数据与比较视图保留。本批记录以此文档及PR为准。

96项自动测试、构建和JavaScript语法检查通过。代码复核修复固定页头高度与同坐标型号标签重叠；本地浏览器验收另修复窄屏图例裁切、领域/模组切换后表格横滚偏移、刷新率重复刻度及型号/地区说明粘连。

已在Chromium的1440×900、768×1024、390×844、320×844视口复验，覆盖手机三模组、XR、44次指标轴切换、缺失值和无点状态、定义/出处锚点、窄屏横向滚动与完整型号图例。页面无横向溢出、控制台无error/warn。补丁在原候选副本中重放后，三个源文件与两个生成文件和验收版本逐字节相同。

这不替代实体手机、Safari、Firefox或全部辅助技术兼容性验收。Google规格链接在本地正常访问下进入地区选择页，未绕过限制；该本地访问不能称为直接规格内容核验，不因此推断数据错误或链接失效。此前规格内容的文字核验范围保留。
