# 光纤耦合：回损、反射与参考面

EVD-004f；候选v0.1.26。定义、原始实验与条件化连接器限值已准备，尚待发布验收。

## 宏观定位与证据范围

本批解决前向插损不能替代返回抑制的问题。Chanclou等的GRADISSIMO研究（Applied Optics 40:458–460，2001，DOI10.1364/AO.40.000458）在平端面单模光纤上组合无芯硅纤与GRIN段。作者稿于2024上传arXiv，不能当2024新实验。5页正文已读，实际查看作者稿pp.2–4的Figs.1–4；没有原始数据或独立复现实验。

ITU原文的核验限于相关段：G.671 (11/2025) §3.2.2.38、§6通用条件及§6.7；G.957 (03/2006) §6.3.3、Appendix I.1；G.650.3 (08/2017) Scope和§6.2.7。官方目录本次均标In force；不代表全部引用标准或所有产品认证已核。G.671实际查看PDF pp.23/30/31/37，G.957 p.28，G.650.3 p.13。印刷页与PDF序号分别记录在来源中。

## 方法、符号与量纲

指定同一端口，反射功率比ρ=Pr/Pi无量纲；R=10log10ρ，RL=−R。返回减少10倍时RL增加10 dB。ρ=1对应0 dB，ρ→0给数学上的无限回损；实际未检出必须按校准和噪声底给界限。负反射值与正回损方向相反；它们都不能表示前向插损。

G.957 Appendix I.1采用耦合器两路标定和背景扣除：ρ=Ps(PR−P0)/(P13P32)，分子/分母均为功率平方。若所有功率单位同乘常数，结果不变；PR≤P0时对数无效，不能用裁成零再声称无限回损（本库数学边界说明）。该式属于所述OCWR装置，不直接声称Chanclou的WIN-R采用相同处理。

G.650.3区分总链路ORL与OTDR离散事件反射；G.671器件定义另说明连接器/未终接端口的额外贡献边界。门宽、返回模式、参考面和偏振是实际比较条件，不能只比较一个dB数。

## 图表与实验解释

Chanclou Fig.1为返回模式耦合示意；Fig.2的纵轴写return-loss但画负值，按反射水平理解。400 μm硅纤/248 μm GRIN示例报告−30.2 dB；换成正回损30.2 dB，对应约0.0955%返回功率，不是0.0955%前向损失。仪器量程0–100 dB和accuracy ±2 dB不等于样品回损或标准不确定度。

Fig.4实线是模型，点是实验；作者讨论的28 dB量级与示例30.2 dB不构成同一统计量。部分散点低于模型曲线，作者联系未抛光端面的缺陷及光斑尺寸解释。未估读散点极值、样本数、标准差或量产良率。两接续界面正文写均低于−80 dB，而Fig.3分别标<−90/<−80 dB；作为上界保留，不冒充精确值。

## 标准的条件与迁移限制

G.671 §6.7连接器表的反射上限−35 dB须连同Notes7/8阅读。Note8对G.982范围以外网络允许−27 dB，仍要求关注多器件系统功能；−40 dB是研究中。Note7讨论扩展温度范围；表下注还包括插拔耐久。该例说明“标准数字”也有任务边界，不给任意微透镜或整链路设置统一35 dB线。

单纤连接器0.5 dB插损和两工作窗口只是同一条款的条件化参数，不与2001微光学样机直接判优劣。没有读取被引用IEC的完整测试步骤，不声称样品通过现行认证。

## 后续与出处

可相信：模式返回抑制与前向耦合需分别量测，回损有清楚的功率和符号约定。尚缺：科研样品的偏振/带宽、完整校准参考面、同件前向插损和独立重复统计。下一步应取得可同时报告回损、插损及对准容差的独立样本，而不是拿仪器量程或理论最优替代实验。
