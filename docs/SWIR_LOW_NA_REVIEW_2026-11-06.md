# SWIR成像与低NA中继实验核验

v0.1.25已公开发布；PR #41与Pages42245329001成功，线上Chrome桌面/手机验收通过。EVD-001e限定文字交付完成，EVD-011b仍需完整实测条件。目录只收实际取得的证据，阅读范围分级。

## 宏观定位

Dupre等（IISW 2023，DOI 10.60928/0mhu-kr31）研究硅光学与SWIR传感器集成。原始4页论文已读，并实际查看pp.3–4的Fig.2、Table1与Fig.3。两个完整堆叠方案是设计模拟，实物只证明初步成像；不能把完整系统性能归给该样机。

Balli等（Nanophotonics 2021，DOI 10.1515/nanoph-2020-0550）为低NA可见至SWIR成像提供独立团队样本。出版社正文与SI可检索文本已读；主文图像及SI示意图尚未视觉核验。本批仅收文字条件，不判断图像最细可辨元素或估读效率曲线。主文和SI属于同一研究。

## 方法与测量链

- Dupre：1550 nm、3 mm直径硅样机配商用InGaAs探测器；与眼动/iTOF模拟配置分开。表列z height不是本库已验证的TTL。UV光刻和完整单片相机是未来计划，不是量产证据。
- Balli：200 μm、NA0.04样品的物距约30 mm，后接可变位置的Newport M-10X中继；最终倍率没有补猜。宽带与RGB使用不同相机，不能将可见RGB当SWIR颜色。SI中放大率公式/距离符号尚需原页核对，本批不采用公式反算。
- EMVA 1288 Release 4.0 General（2021-06-16）官方PDF已取得，实际查看p.28 §8.6。只使用其v/N频率与v=N/2奈奎斯特约定，不声称全文认证审核或最新版状态核验。

## 图表与量纲复核

Dupre Fig.2显示光线、光斑与MTF曲线；本库只录Table1明示值，不从小图反推模拟波长或场点平均。眼动和iTOF像元分别2.5/5 μm，表内MTF @ Ny/2分别55%/70%。正文对后者用“超过70%”，保留差异。以规则采样网格作单位换算：Ny=500/p（p用μm，结果lp/mm），两方案Ny/2分别100/50 lp/mm。因此百分比不是同频比较，也不是实物验收值。90°的H/V/对角口径未标，不改写为DFOV。Fig.3可见USAF图像，但没有足以支持本库独立分辨率判定的标靶组号/阈值和测量条件。

Balli主文§3效率段写20/100 μm，制造/成像段写20/200 μm；42%归属冲突未解，不把它默认为200 μm成像效率。另一20 μm样品60%也不移用。SI中的650–1750 nm校准段、45.3 lp/mm标靶描述以及公式不构成本批新增实测分辨率或全波段MTF。

## 批判与迁移

这些证据支持按光谱响应、共轭、中继、像元采样和MTF评价成像任务；不支持一个通用优先级或全球最佳。低NA样本不能直接与不同孔径、带宽、处理链的科研/商业系统排名。后续最有价值的是：取得Balli图页核可辨尺度与口径冲突；寻找报告物距/实际MTF/效率和误差的独立SWIR样机；用同一物/像方空间频率建立可比较集合。EVD-011b和父EVD-001/011仍保留未满足条件，不以本批候选记录关闭整体要求。
