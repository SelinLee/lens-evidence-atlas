本文件持续维护，状态不等于科学结论已获独立同行评审。优先少量可审核问题，不按数量补齐。

## 第一优先

- [x] P1-LOWNA-01：收录 Wang 2021 NA0.1 元件实测效率及分母，归入 app_04 候选元件；不等同完整显微系统。
- [ ] P1-LOWNA-02：寻找至少第二个独立原始研究，统一NA侧别/介质、孔径、波段采样、效率分母/焦圈、焦面和偏振。Wang样本量及逐波长焦面未核验，不能与Richards或商业物镜形成最优集合。
- [x] P1-SHEET-01：拆分 Luo 2025 照明FWHM6.8 μm和系统横向PSF约1.7 μm，记录同篇来源与有限珠尺寸。
- [ ] P1-SHEET-02：核验44.3%透过效率的分母/收集范围，以及正文1.1/1.7 μm、800/850 nm差异；合法取得SI后检查原图和测量定义。不得把FOV直接当统一定义的有效传播长度。
- [x] P1-MLA-01：视觉核对 Richards 主方案效率分母、Fig.2/3、离散波长焦移，明确实验/模拟不同口径。
- [ ] P1-MLA-02：核验补充材料与独立阵列实验的串扰、填充率、焦长均匀性及固定焦面宽带效率；阵列成像演示不自动证明全部阵列指标。
- [x] P1-SMF-01：收录 Jovanovic 2017 实验室约78%注入；区分86%相对理论值、MMF参考分母、端面反射校正和端到端损耗。
- [ ] P1-SMF-02：补第二个独立同条件实验；固定瞳形/变迹、波前质量、光纤模场、偏振、光谱通道、校准分母与系统边界。f/5.3未直接验证，不转写实测NA。
